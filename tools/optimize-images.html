Image optimizer

Makes your pictures small (WebP) so the website opens fast. Everything happens in your browser, nothing is uploaded anywhere.

  1. Click Choose folder and pick your assets folder (or drop it below).
  2. Check the sizes in the table, then click Optimize.
  3. Click Download ZIP, extract it and upload the files to GitHub (same folders).

The website finds foto1.webp even when data-games.js says foto1.jpg, so you do not have to change any path.

Maximum width in pixels per folder. The first keyword found in the path wins. 0 = leave the picture alone.
